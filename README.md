# 🎩 Шляпа — браузерная командная игра

Чистые HTML, CSS и JavaScript (ES-модули). Без фреймворков, сборки и сервера — только статические файлы.

## Запуск

Словари загружаются через `fetch`, поэтому открывать `index.html` двойным кликом (`file://`) нельзя — нужен любой простой HTTP-сервер:

```bash
cd hat-game
python3 -m http.server 8000      # или: npx serve
```

Откройте http://localhost:8000. Чтобы играть с телефона, откройте адрес `http://<IP-компьютера>:8000` в той же Wi-Fi сети.

Положите свои словари в `resources/` (по одному слову или словосочетанию на строку, UTF-8):
`easy.txt`, `normal.txt`, `normal2.txt`, `hard.txt`, `very_hard.txt`, `celebrities.txt`, `collocations.txt`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Каркас страницы, подключение `js/main.js` |
| `css/style.css` | Стили: переменные, mobile-first, анимации |
| `js/main.js` | Инициализация, события, связь модулей, поток «передача → отсчёт → ход → результаты» |
| `js/game.js` | Правила: раунды, ходы, «Отгадано»/«Пропустить», очки, статистика, победитель |
| `js/words.js` | Загрузка и очистка словарей, сборка базы по сложности и пропорциям |
| `js/teams.js` | Деление на команды, обмен игроков, вычисление очереди ходов |
| `js/timer.js` | Таймер по времени окончания (`Date.now`), обратный отсчёт 3-2-1 |
| `js/ui.js` | Разметка всех экранов |
| `js/storage.js` | localStorage: настройки, звук, прогресс игры |
| `js/sound.js` | Звуки на Web Audio API, отключаются кнопкой 🔊 |
| `js/utils.js` | Перемешивание, склонение слов |

## Как устроено

- **Состояние** — один объект `state` (`game.js`). `state.words` — неизменяемая база; `state.pool` — рабочий пул раунда (id неотгаданных слов). В новом раунде пул заново создаётся из `words` и перемешивается.
- **Пропущенное слово** остаётся в пуле; удаляется только по «Отгадано». Недоотгаданное слово при конце времени тоже остаётся в пуле.
- **Очередь**: порядок вычисляется из `turnCounter` (команды чередуются, игроки по кругу) и сохраняется во всех трёх раундах.
- **Защита от багов**: `endTurn` идемпотентен; кнопки блокируются на 250 мс; если время вышло в момент нажатия — очко не засчитывается.
- **Сохранение**: прогресс пишется в `localStorage` после каждого действия. После перезагрузки на главной появится «Продолжить игру»; незаконченный ход начнётся заново с экрана передачи телефона (уже отгаданные в нём слова остаются засчитанными).
- **Состав базы**: средний и сложный режимы — на каждые 10 слов 1 знаменитость и 1–2 словосочетания, остальное обычные слова; все слова уникальны (в том числе между словарями). Если словаря не хватает, игра не начинается и показывает, в каком файле.
